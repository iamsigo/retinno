# RETINNO Theme — قالب اختصاصی رتینو

قالب کلاسیک و سبک وردپرس برای سایت فارسی رتینو؛ نسخه 1.3.0 با تجربه بصری شاخص‌تر، راهنمای تعاملی انتخاب قدم بعدی، بخش پرسش‌های بازشونده و بهبود حرکت‌های ظریف رابط، هماهنگ با هویت RETINNO Concept A Ultra Minimal. این قالب با PHP، CSS و JavaScript پیاده‌سازی شده و به‌صورت پیش‌فرض RTL سایت را از تنظیمات زبان وردپرس می‌گیرد. هیچ فونت، اسکریپت یا کتابخانه خارجی از CDN بارگیری نمی‌شود.

> **سیستم طراحی:** پالت پایه این نسخه مطابق برد هویت بصری RETINNO Concept A Ultra Minimal تنظیم شده است: Deep Navy `#0B1324`، Blue Accent `#3B82F6`، Slate `#94A3B8` و Light `#F8FAFC`. لوگوی کامل سایت همچنان از گزینه «هویت سایت» در وردپرس خوانده می‌شود؛ اگر لوگوی سفارشی تنظیم نشده باشد، قالب از نشان R داخلی استفاده می‌کند.

## پیش‌نیازها

- WordPress 6.3 یا جدیدتر
- PHP 8.0 یا جدیدتر
- افزونه `RETINNO Core` فعال باشد تا نوع محتوای «مشاوران» و taxonomyهای `consultant_field` و `consultant_grade` ثبت شوند.
- افزونه Advanced Custom Fields فعال باشد تا فیلدهای پروفایل مشاوران نمایش داده شوند.
- Elementor و Elementor Pro می‌توانند نصب و فعال باقی بمانند، اما این قالب برای هدر، فوتر، خانه، بلاگ و پروفایل مشاوران به Elementor وابسته نیست.

## نصب روی لوکال

1. از پوشه سایت فعلی یا حداقل دیتابیس و `wp-content` بکاپ بگیر.
2. در پیشخوان وردپرس برو به **نمایش ← پوسته‌ها ← افزودن پوسته تازه ← بارگذاری پوسته**.
3. فایل `retinno-theme-install.zip` را بارگذاری و نصب کن.
4. پس از نصب، **فعال‌سازی** را بزن. لازم نیست Hello Elementor را حذف کنی؛ فقط قالب فعال را عوض می‌کنیم.
5. مطمئن شو افزونه‌های `RETINNO Core` و ACF فعال مانده‌اند.
6. از **تنظیمات ← پیوندهای یکتا** بدون تغییر گزینه‌ها، روی **ذخیره تغییرات** کلیک کن تا مسیر آرشیو مشاوران تازه‌سازی شود.

## تنظیمات اولیه وردپرس

1. در **تنظیمات ← عمومی** زبان سایت را فارسی انتخاب کن.
2. یک برگه با عنوان «خانه» بساز و در **تنظیمات ← خواندن** آن را به‌عنوان صفحه نخست انتخاب کن. فایل `front-page.php` چیدمان خانه را رندر می‌کند؛ محتوای برگه خانه برای این طرح اولیه استفاده نمی‌شود.
3. یک برگه با عنوان «مجله رتینو» و نامک `blog` بساز و آن را به‌عنوان «برگه نوشته‌ها» در **تنظیمات ← خواندن** انتخاب کن. قالب `home.php` فهرست نوشته‌های بلاگ را می‌سازد.
4. لوگوی نهایی را از **نمایش ← سفارشی‌سازی ← هویت سایت** یا گزینه لوگوی سایت در پنل وردپرس بارگذاری کن.
5. از **نمایش ← فهرست‌ها** یک فهرست اصلی بساز و به محل «منوی اصلی» وصلش کن. محل «منوی فوتر» هم اختیاری است؛ تا وقتی منوها تعریف نشده‌اند، قالب منوی جایگزین دارد.
6. برگه‌های «درباره ما»، «خدمات» و «ارتباط با ما» را هر زمان آماده شدند بساز. منوی جایگزین فقط برگه‌های موجود با نامک‌های `about`، `services` و `contact` را نشان می‌دهد.

## قالب‌ها و قابلیت‌ها

- `index.php`: قالب اصلیِ الزامی و fallback وردپرس
- `front-page.php`: صفحه خانه با Hero امضادار، معرفی رویکرد، راهنمای تعاملی «از کجا شروع کنم؟»، مشاوران، مجله و پرسش‌های پرتکرار
- `archive-retinno_consultant.php`: فهرست مشاوران
- `single-retinno_consultant.php`: صفحه اختصاصی هر مشاور
- `home.php`: فهرست نوشته‌های بلاگ
- `single.php`: صفحه مقاله
- `author.php`: صفحه نویسنده برای وبلاگ چندنویسنده‌ای
- `page.php`: برگه‌های عادی
- `archive.php`, `search.php`, `404.php`: قالب‌های عمومی
- `assets/css/main.css`: توکن‌های هویت بصری، layoutها و responsive styles
- `assets/images/retinno-mark-dark.png`: نشان R تیره برای پس‌زمینه روشن
- `assets/images/retinno-mark-light.png`: نشان R روشن برای سطح تیره
- `assets/js/main.js`: رفتار منوی موبایل، تب‌های راهنمای مسیر با پشتیبانی صفحه‌کلید و نمایش تدریجی محتوا در مرورگرهای سازگار

## فیلدهای ACF مورد انتظار برای مشاوران

نامک نوع محتوا: `retinno_consultant`

| نام فیلد | کاربرد |
| --- | --- |
| `short_intro` | معرفی کوتاه |
| `resume` | رزومه / معرفی کامل |
| `education` | سوابق تحصیلی |
| `achievements` | سوابق و دستاوردها |
| `consulting_experience` | سابقه مشاوره |
| `capacity_status` | وضعیت ظرفیت |

مقادیر `capacity_status`:

- `available` — دارای ظرفیت
- `limited` — ظرفیت محدود
- `full` — تکمیل ظرفیت
- `inactive` — فعلاً پذیرش ندارد

تصویر شاخص از Featured Image وردپرس گرفته می‌شود. دسته‌های رشته و پایه از taxonomyهای `consultant_field` و `consultant_grade` خوانده می‌شوند.

## توکن‌های طراحی

در ابتدای `assets/css/main.css` متغیرهای CSS قرار دارند. تغییر رنگ اصلی، پس‌زمینه، متن، حاشیه‌ها، فاصله‌ها و گردی گوشه‌ها از همان‌جا انجام می‌شود. نشان‌های fallback برند در پوشه `assets/images` قرار دارند و پالت فعلی همان رنگ‌های تثبیت‌شده رتینو است. برای حفظ هویت بصری، رنگ‌های پایه را در همین متغیرها تغییر بده؛ رنگ آبی روشن نقش accent دارد و برای متن‌های تعاملی کوچک از آبی تیره‌تر با کنتراست بالاتر استفاده می‌شود.

## محدودیت‌های نسخه اولیه

- این نسخه زیرساخت و طراحی پایه را فراهم می‌کند؛ فیلتر AJAX مشاوران، رزرو، پرداخت و اتصال تلگرام عمداً هنوز پیاده‌سازی نشده‌اند.
- دکمه‌های اصلی به صفحه فهرست مشاوران یا مجله هدایت می‌شوند و هیچ فرآیند جذب/پرداختی را ادعا یا اجرا نمی‌کنند.
- پیش از انتشار روی هاست واقعی باید نسخه PHP، URLها، پیوندهای یکتا، فرم‌ها، افزونه‌های کش/امنیت و تنظیمات SEO در محیط مقصد بررسی شوند.


## تغییرات نسخه 1.1.0

- کارت‌های مشاوران با عکس برجسته‌تر، وضعیت ظرفیت خواناتر، ارتفاع منظم‌تر و حالت جایگزین برندشده برای نبود عکس بهبود یافته‌اند.

- اطلاعات مشاوران، فیلدهای ACF، ساختار منوها و نوع نوشته سفارشی بدون تغییر باقی مانده‌اند.


## تغییرات نسخه 1.2.0
- رنگ متن لینک‌ها، حالت فعال منو و دکمه‌های اصلی برای خوانایی بهتر و کنتراست بالاتر تنظیم شد؛ آبی برند `#3B82F6` همچنان رنگ accent طراحی است.

- تصاویر کارت‌ها با `decoding=async` رندر می‌شوند و خروجی responsive image خود وردپرس حفظ شده است.
- چیدمان Hero در نمایشگرهای بسیار باریک و شکستن نام‌های طولانی فارسی بهبود یافت؛ افکت hover روی دستگاه‌های لمسی حذف شد.
- سبک‌ها برای حالت forced-colors و نسخه‌های قدیمی‌تر Safari تکمیل شدند.
- ساختار نوع محتوای مشاوران، taxonomyها، کلیدهای ACF، منوها و مسیرهای محتوایی تغییر نکرده‌اند.

## وضعیت آزمون
این بسته از نظر ساختار ZIP، تطابق فایل‌های نصب و سورس، هماهنگی شماره نسخه، نحو PHP و بررسی نحوی JavaScript بررسی می‌شود. چون این محیط به وردپرس محلی شما و دیتابیس XAMPP متصل نیست، آزمون واقعی در پیشخوان و رندر نهایی مرورگر روی سیستم شما در اینجا قابل تأیید نیست؛ پیش از جایگزینی قالب فعلی، بکاپ بگیر و چک‌لیست راهنمای به‌روزرسانی را اجرا کن.
